# The Tower — Interactive Narrative Development

An employer-facing development repository for an interactive adaptation of **The Tower**, an original long-form story project.

This repository documents the process of translating a linear narrative into an Ink-based interactive story while preserving the authored dramatic spine.

## Portfolio focus

The current playable slice follows **Jodie from Filtration 123 to Medical Intake**.

The design uses a mostly linear route with persistent state:

- character attributes such as curiosity, defiance, and solidarity
- relationship values such as Brooks trust and Tyler trust
- knowledge and action flags that can unlock later dialogue, actions, and short branches
- selective real branching where a divergence earns meaningful story value

The player is not primarily choosing where the story goes. The player is shaping **who Jodie becomes while she gets there**.

## Current route

Filtration 123 → Sail Rigging → Living Quarters → Water Storage → Agro → Distribution → Elevator Shaft → Medical Intake
